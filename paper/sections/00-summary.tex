\paragraph{What this report is.} \texttt{FL-CKD-Flower} is the \textbf{methodology test bed} for
FLIP-IT. Currently FL-CKD-Flower is run on \NumPractices{} synthetic practices totalling
\NumPatients{} generated patients. The \emph{method} is therefore described definitively while
\emph{measurements} are labelled as test-bed evidence. The status chip on each section keeps the
two apart, and \S\ref{sec:realdata} states explicitly which conclusions survive the move to real
practice data and which do not.
