\paragraph{What this report is.} \texttt{FL-CKD-Flower} is the \textbf{methodology test bed} for
FLIP-IT. Currently FL-CKD-Flower is run on \NumPractices{} synthetic practices totalling
\NumPatients{} generated patients. The \emph{method} is therefore described definitively while
\emph{measurements} are labelled as test-bed evidence. The status chip on each section keeps the
two apart, and \S\ref{sec:realdata} states explicitly which conclusions survive the move to real
practice data and which do not.

\paragraph{The deployment standard.} Since the privacy sections were first drafted, the privacy
position has hardened into a built and measured \textbf{deployment standard}: \emph{record-level
DP-SGD inside each practice} (per-record gradient clipping, Gaussian noise on Poisson-sampled lots),
\emph{secure aggregation on the wire}, and a \emph{rule-based server agent} (a deterministic rule
table, not an LLM) that sets each practice's batch size and noise multiplier so every practice
composes to one shared target $\varepsilon^{*}$. Measured on the synthetic cohort
(\texttt{notebooks/03\_dpsgd\_secagg\_standard.ipynb}): utility is flat from
$\varepsilon^{*} = 0.5$ to $8$ at $\varepsilon^{*} = 2$, global AUROC $0.797 \pm 0.011$ and
worst-practice $0.649 \pm 0.060$, against update-level local DP's \LocalAUCOne{} /
\LocalWorstOne{} at composed
$\varepsilon \approx \LocalEpsOne{}$ and verified live end-to-end, including over the masked SecAgg+ rails,
with zero failures. \S\ref{sec:noise}, \S\ref{sec:reduce} and \S\ref{sec:recs} carry the detail.
